# Contributing

Reports and changes from people and from agents are both welcome.

## Where things go

| You have | Use |
| --- | --- |
| A question or setup problem | [Discussions](https://github.com/pauhu/mcp/discussions) |
| A wrong or broken page, on any Pauhu site | [Website problem](https://github.com/pauhu/mcp/issues/new?template=website.yml) |
| A connector or API problem | [Connector or API problem](https://github.com/pauhu/mcp/issues/new?template=connector.yml) |
| An idea | [Idea](https://github.com/pauhu/mcp/issues/new?template=idea.yml) |
| A vulnerability | [SECURITY.md](SECURITY.md), never a public issue |
| Your own account, balance or receipt | [Support](https://pauhu.ai/support), never a public issue |

Search open and closed issues first.

## Changes in this repository

This repository holds the setup docs and the client examples. Pull requests are welcome for these. Keep one change in each pull request and check that any JSON you touch still parses. For site pages, open a Website problem with the exact words you propose.

Contributions are under this repository's licence, Apache-2.0.

## Everyone

Issues are public. Never post keys, tokens, receipts or personal data, yours or anyone else's. If you notice some in an issue, say so without quoting it.
